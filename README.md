\# Техническая документация веб-приложения «Калькулятор сдельно-премиальной зарплаты»



\## О проекте



Учебный командный проект по дисциплине «Информационные системы», в рамках которого было разработано кроссплатформенное веб-приложение для автоматизации расчёта сдельно-премиальной заработной платы сотрудников предприятия ООО «Авиа-строй».



\*\*Моя роль в проекте:\*\* технический аналитик / документатор.



Я отвечала за:

\- Сбор и формализацию требований к системе

\- Разработку Технического задания по ГОСТ 19.201-78

\- Разработку Руководства оператора по ГОСТ 19.505-79

\- Разработку Руководства программиста по ГОСТ 19.504-79

\- Моделирование системы в нотации UML (Use Case, Class, Sequence)

\- Постановку задач для команды разработки

\- Настройку процесса сборки и развертывания (CI/CD через Travis CI + Heroku)



\## Бизнес-контекст



\### Проблема

На предприятии ООО «Авиа-строй» (производство деталей реактивных двигателей) расчёт заработной платы для рабочих цеха выполнялся вручную в Excel. Это приводило к:

\- Высоким временным затратам бухгалтерии

\- Ошибкам в расчётах из-за человеческого фактора

\- Отсутствию прозрачности в начислении премий

\- Сложности учёта районных коэффициентов и МРОТ



\### Решение

Разработано веб-приложение, которое:

\- Автоматически рассчитывает сдельно-премиальную зарплату по формулам

\- Учитывает МРОТ, НДФЛ и районный коэффициент

\- Формирует печатную форму результата в формате .xls

\- Поддерживает две роли: пользователь и администратор

\- Работает кроссплатформенно (Windows, Linux)



\### Целевая аудитория

\- \*\*Пользователь\*\* — сотрудник цеха, вводит данные о выработке

\- \*\*Администратор\*\* — управляет расценками и коэффициентами
