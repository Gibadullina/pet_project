# Бизнес-требования

## Проблема
Расчёт сдельно-премиальной зарплаты на предприятии ООО «Авиа-строй» выполнялся вручную, что занимало до 3 рабочих дней в месяц и приводило к ошибкам в 5% случаев.

## Цели проекта
1. Сократить время расчёта зарплаты с 3 дней до 1 часа
2. Снизить количество ошибок до 0.1%
3. Обеспечить прозрачность начисления премий

## Стейкхолдеры

| Стейкхолдер | Роль | Интерес |
| :--- | :--- | :--- |
| Бухгалтерия | Пользователь | Быстрый расчёт, меньше ошибок |
| Сотрудники цеха | Пользователь | Прозрачность начисления |
| Директор | Заказчик | Экономия ФОТ бухгалтерии |
| IT-отдел | Администратор | Простота поддержки |

## Функциональные требования (связь с Use Case)

| Требование | Use Case | Приоритет |
| :--- | :--- | :--- |
| Авторизация пользователя | Вход в систему | Высокий |
| Ввод данных о выработке | Расчёт зарплаты | Высокий |
| Просмотр результата | Расчёт зарплаты | Высокий |
| Экспорт в Excel | Формирование отчёта | Средний |
| Редактирование расценок | Управление настройками | Средний |

## Метрики успеха
- Время расчёта: ≤ 1 час
- Точность: ≥ 99.9%
- Удовлетворённость пользователей: ≥ 4 из 5
